# 🛡️ Harness Engineering: AI Agent SOP (Standard Operating Procedure)

이 문서는 AI 에이전트가 이 프로젝트에서 업무를 수행할 때 반드시 지켜야 하는 **실행 환경 가이드라인**입니다.

## 1. 작업 시작 (Pre-task)
- 모든 작업 시작 전, 현재 디렉토리 구조를 확인하고 `index.html`의 최근 상태를 읽어야 합니다.
- 사용자가 준 `RULE[user_global]`과 이 `SOP.md`를 결합하여 작업 계획을 수립합니다.
- **체크리스트:**
    - [ ] `index.html`의 `<title>`과 메타 태그가 목적에 부합하는가?
    - [ ] 사용 중인 외부 라이브러리(EmailJS, Google Fonts 등)의 설정을 확인했는가?

## 2. 작업 중 (In-task)
- **Premium Design 가드레일:**
    - 모든 색상은 변수화되어 있어야 하며, 가급적 HSL을 사용합니다.
    - 애니메이션은 `cubic-bezier` 혹은 부드러운 `ease-in-out`을 사용합니다.
    - 반응형 대응은 필수이며, 모바일 퍼스트 혹은 적절한 브레이크포인트를 유지합니다.
- **코드 무결성:**
    - 기존의 `data-i18n` 다국어 시스템을 파괴하지 않아야 합니다.
    - 인라인 스타일을 최소화하고 클래스 기반 스타일링을 지향합니다.

## 3. 작업 완료 및 검증 (Post-task)
- 작업을 마치기 전 반드시 아래 명령어를 실행하여 자동 검증을 수행합니다.
  ```bash
  node .harness/validator.js
  ```
- 검증 결과 오류가 있다면 스스로 수정하고 다시 검증합니다.
- 최종 보고 시, 검증 통과 여부를 사용자에게 알립니다.

## 4. 에러 대응
- 예상치 못한 에러 발생 시 `RULE[user_global]`의 **Debugging Workflow**를 따릅니다.
- 하네스 검증기가 반복적으로 실패할 경우, 해당 규칙이 현재 작업과 충돌하는지 분석하여 사용자에게 보고합니다.
